# ⚡Projeto de cálculo de consumo de energia elétrica mensal⚡

📖Este projeto foi feito em Python como parte da atividade da semana e visa fazer um cálculo de consumo mensal de aparelhos elétricos em kWh e trazer também o valor do consumo em Reais.
Para executar o programa abra o terminal do projeto e digite **python app.py** e a seguir basta inserir o **nome** do aparelho elétrico, a **potência** do aparelho em watts e o **tempo médio** de uso diário do aparelho em horas.
O programa faz o seguinte calculo com as informações dadas:
```
consumo_mensal = (potencia * horas_diarias * 30) / 1000
```
E usa como valor fixo de preço:
```
valor_kwh = 0.50
```
